## 1. 背景与目标

### 1.1 产品定位

PixelArt Studio 是一款纯前端的图片像素化工具，用户上传图片后，可通过直观的参数调整界面，实时预览并生成像素艺术风格图片。所有处理在浏览器本地完成，无需上传图片到服务器。

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 零成本 | 纯静态站点，部署到免费 CDN 即可运行 |
| 零上传 | 图片全程本地处理，保护用户隐私 |
| 实时预览 | 参数调整即时反馈，所见即所得 |
| 一键导出 | 支持多种格式和分辨率输出 |

### 1.3 目标用户

| 用户类型 | 使用场景 | 核心需求 |
|----------|----------|----------|
| 像素艺术爱好者 | 将照片转为像素风格 | 丰富的预设和自定义选项 |
| 独立游戏开发者 | 生成复古游戏素材 | 硬件精确模拟、Sprite Sheet 导出 |
| 设计师 | 制作像素风头像/插画 | 高质量输出、精细参数控制 |
| 普通用户 | 制作趣味头像 | 操作简单、效果直观 |

### 1.4 成功指标

- 页面加载时间 < 2s（首次访问）
- 参数调整到预览更新延迟 < 200ms（缩略图模式）
- 支持的最大图片尺寸：4096×4096
- 支持的输出格式：PNG、Sprite Sheet

## 2. 用户画像

### 2.1 用户旅程

```
发现工具 → 上传图片 → 调整参数 → 预览效果 → 导出下载
   │           │           │           │           │
   │           │           │           │           ▼
   │           │           │           │      [分享/使用]
   │           │           │           ▼
   │           │           │      [不满意 → 继续调整]
   │           │           │      [满意 → 导出]
   │           │           ▼
   │           │      [选择预设]
   │           │      [调整像素块大小]
   │           │      [框选局部区域]
   │           ▼
   │      [拖拽上传]
   │      [或点击选择]
   ▼
[社交媒体/搜索引擎]
[朋友推荐]
```

### 2.2 主要使用流程

**流程 A：快速体验**
1. 打开网页
2. 拖放图片到上传区
3. 选择内置预设（如 GameBoy）
4. 点击导出下载

**流程 B：精细调整**
1. 上传图片
2. 裁剪到目标区域
3. 框选需要像素化的范围
4. 调整像素块大小和算法
5. 选择或自定义调色板
6. 对比确认效果
7. 导出高清版本

**流程 C：人物像素风**
1. 上传人物照片
2. 选择人物模式（Normal/Cutout/Style/Sprite）
3. 如选 Cutout：自动分割人像，背景可选保留或像素化
4. 如选 Sprite：上传多角度的照片，统一处理后拼接
5. 导出

## 3. 术语表

| 术语 | 说明 |
|------|------|
| 像素化 (Pixelization) | 将图片转换为低分辨率块状效果的处理过程 |
| 降采样 (Downsample) | 降低图片分辨率后再放大，形成像素块 |
| 颜色量化 (Quantization) | 将图片颜色数量缩减到有限数量的过程 |
| 调色板 (Palette) | 一组预定义的颜色集合，用于限制输出颜色 |
| 选区 (Selection) | 用户在图片上框选的处理范围 |
| 选区遮罩 (Mask) | 定义选区内外的二值图像，用于局部处理 |
| Sprite Sheet | 将多个角色/动作帧排列在一张图片上的格式 |
| 中位切分 (Median-cut) | 一种自适应颜色量化算法 |
| Dithering | 通过散布像素点模拟更多颜色的技术 |
| Web Worker | 在浏览器后台线程中执行 JavaScript 的机制 |

### 4.2 详细功能说明

#### F-01 图片上传

**需求描述：**
- 支持点击上传和拖拽上传两种方式
- 支持格式：PNG、JPEG、WebP
- 支持的最大文件大小：20MB
- 上传后显示图片预览

**验收标准：**
- [ ] 点击上传区可打开系统文件选择器
- [ ] 拖拽图片到上传区可触发上传
- [ ] 不支持的文件格式显示错误提示
- [ ] 超过大小限制显示错误提示
- [ ] 上传成功后图片显示在中央画布

#### F-02 图片裁剪

**需求描述：**
- 提供裁剪工具，可调整裁剪框大小和位置
- 裁剪可独立使用，不强制要求
- 裁剪后可继续框选和像素化处理

**验收标准：**
- [ ] 点击裁剪工具后显示裁剪框
- [ ] 裁剪框可拖拽调整位置
- [ ] 裁剪框可拖拽边角调整大小
- [ ] 确认裁剪后画布显示裁剪后的图片
- [ ] 取消裁剪可恢复到原图

#### F-03 框选工具

**需求描述：**
- 支持四种框选方式：矩形、圆形、多边形点选、自由手绘
- 框选后显示选区边界（虚线或高亮）
- 可删除或重新绘制选区

**验收标准：**
- [ ] 矩形框选：点击并拖拽绘制矩形
- [ ] 圆形框选：点击中心点后拖拽确定半径
- [ ] 多边形框选：点击多个顶点形成闭合多边形，双击完成
- [ ] 自由手绘：按住鼠标拖拽绘制任意路径，释放后自动闭合
- [ ] 选区可删除（按 Delete 键或点击删除按钮）
- [ ] 选区可移动或调整大小

#### F-04 反向选区

**需求描述：**
- 提供"反转选区"开关
- 默认状态：选区内像素化，选区外保持原样
- 反转状态：选区外像素化，选区内保持原样

**验收标准：**
- [ ] 提供 Invert 开关（toggle）
- [ ] 开关状态实时反映在预览中
- [ ] 状态保存到历史记录

#### F-05 像素块调整

**需求描述：**
- 滑块控制像素块大小，范围 2~64
- 实时预览更新
- 可输入精确数值

**验收标准：**
- [ ] 滑块范围 2~64
- [ ] 拖动滑块时缩略图实时更新（延迟 < 200ms）
- [ ] 松开滑块后 0.5s 用原图生成高质量预览
- [ ] 支持直接输入数值

#### F-06 降采样算法

**需求描述：**
- 提供两种算法：Nearest（最近邻）和 Average（平均采样）
- 默认使用 Nearest
- 切换后实时预览

**验收标准：**
- [ ] 提供算法切换按钮/下拉菜单
- [ ] Nearest 效果锐利，每个像素块颜色一致
- [ ] Average 效果平滑，像素块内颜色有过渡
- [ ] 切换后预览即时更新

#### F-07 颜色量化

**需求描述：**
- 三种量化模式：None（不量化）、Median-cut（自适应）、Fixed-palette（固定调色板）
- Median-cut 模式下可调整最大颜色数（2~256）
- Fixed-palette 模式下使用当前选中的预设调色板

**验收标准：**
- [ ] 提供量化模式选择
- [ ] Median-cut 下颜色数滑块可用，其他模式禁用
- [ ] 颜色数调整后实时预览
- [ ] 固定调色板模式下颜色严格限制为调色板中的颜色

#### F-08 内置预设

**需求描述：**
- 内置两类预设：硬件模拟和创意主题
- 硬件模拟：GameBoy、NES、CGA、EGA
- 创意主题：Cyberpunk、Vaporwave、Wasteland、Mono
- 预设以分类列表展示，点击应用

**验收标准：**
- [ ] 预设列表按分类组织（Hardware / Theme）
- [ ] 点击预设后立即应用并更新预览
- [ ] 预设包含完整的处理参数（降采样、量化、调色板等）
- [ ] 应用预设后，参数面板同步显示对应值

**预设详细配置：**

| 预设 | blockSize | algorithm | quantize | maxColors | 调色板 |
|------|-----------|-----------|----------|-----------|--------|
| GameBoy | 4 | nearest | fixed-palette | 4 | #0f380f, #306230, #8bac0f, #9bbc0f |
| NES | 2 | nearest | fixed-palette | 56 | NES 标准调色板 |
| CGA | 3 | nearest | fixed-palette | 4 | #000000, #55ffff, #ff55ff, #ffffff |
| EGA | 2 | nearest | fixed-palette | 16 | EGA 标准调色板 |
| Cyberpunk | 4 | nearest | fixed-palette | 8 | 霓虹色系 |
| Vaporwave | 4 | average | median-cut | 16 | 自适应 |
| Wasteland | 6 | average | median-cut | 8 | 自适应 |
| Mono | 4 | nearest | fixed-palette | 2 | #000000, #ffffff |

#### F-09 自定义调色板

**需求描述：**
- 提供调色板编辑器，可添加/删除/修改颜色
- 颜色数量限制：2~32
- 可保存为个人预设，命名后存入 localStorage
- 可删除已保存的个人预设

**验收标准：**
- [ ] 提供颜色选择器添加颜色
- [ ] 点击已添加颜色可修改或删除
- [ ] 显示当前颜色数量
- [ ] 提供"保存为预设"按钮，弹出命名对话框
- [ ] 保存后的预设出现在"Custom"分类下
- [ ] 可删除自定义预设（带确认对话框）

#### F-10 对比视图

**需求描述：**
- 提供两种对比模式：并排（Split）和滑块（Slider）
- 并排模式：左半原图，右半效果图
- 滑块模式：可拖拽的分界线，左侧原图右侧效果图
- 可开关对比视图

**验收标准：**
- [ ] 提供对比视图开关
- [ ] 并排模式下左右等分显示
- [ ] 滑块模式下可拖拽分界线
- [ ] 滑块拖拽流畅，无卡顿
- [ ] 关闭对比视图后恢复单图显示

#### F-11 人物像素风

**需求描述：**
- 四种模式：Normal、Cutout、Style、Sprite
- **Normal**：与普通图片相同处理
- **Cutout**：自动分割人像主体，背景可选保留或像素化
- **Style**：轮廓增强 + 特定配色，更像手绘像素画
- **Sprite**：多图输入，统一像素化后拼接为 Sprite Sheet

**验收标准：**
- [ ] 提供四种模式选择器
- [ ] Normal 模式下与普通图片处理一致
- [ ] Cutout 模式下自动识别人像并分割（使用 @mediapipe/selfie-segmentation）
- [ ] Cutout 模式下提供"背景处理方式"选项（保留原样/像素化/纯色填充）
- [ ] Style 模式下自动增强边缘轮廓
- [ ] Sprite 模式下支持上传多张图片（最少 1 张，建议 4~8 张）
- [ ] Sprite 模式下提供布局选项（水平排列/网格排列）

#### F-12 Sprite Sheet 导出

**需求描述：**
- 将多张照片统一像素化处理后拼接为一张 Sprite Sheet
- 支持水平排列和网格排列两种布局
- 可设置帧间距（padding）
- 导出为 PNG

**验收标准：**
- [ ] 上传多张照片后显示缩略图列表
- [ ] 可对每张照片单独调整像素化参数或统一应用
- [ ] 提供布局选择：Horizontal / Grid（2×2, 3×3, 4×4）
- [ ] 提供帧间距设置（0~20px）
- [ ] 实时预览 Sprite Sheet 布局
- [ ] 导出为单张 PNG

#### F-13 撤销/重做

**需求描述：**
- 支持操作历史，可撤销和重做
- 历史记录保存的参数快照包括：处理参数、选区、预设选择
- 快捷键支持：Ctrl+Z 撤销，Ctrl+Shift+Z 重做

**验收标准：**
- [ ] 提供撤销/重做按钮
- [ ] 支持 Ctrl+Z / Ctrl+Shift+Z 快捷键
- [ ] 撤销后所有参数和预览恢复到之前状态
- [ ] 重做后恢复到撤销前的状态
- [ ] 新操作后清空 redo 栈

#### F-14 PNG 导出

**需求描述：**
- 导出处理后的图片为 PNG 格式
- 使用原图分辨率生成高质量输出
- 提供下载对话框或自动触发浏览器下载

**验收标准：**
- [ ] 点击导出按钮后弹出导出选项
- [ ] 导出使用原图分辨率（非缩略图）
- [ ] 自动触发浏览器下载
- [ ] 文件名默认：`pixelart_[timestamp].png`

## 5. 非功能需求

### 5.1 性能

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 首次加载时间 | < 2s | 3G 网络下 |
| 参数调整到预览更新 | < 200ms | 缩略图模式（800px） |
| 原图导出处理时间 | < 5s | 1920×1080 图片 |
| 最大支持图片尺寸 | 4096×4096 | 超出提示压缩 |
| 内存占用 | < 200MB | 处理过程中 |

### 5.2 浏览器兼容性

| 浏览器 | 最低版本 | 说明 |
|--------|----------|------|
| Chrome | 90+ | 完全支持 |
| Firefox | 88+ | 完全支持 |
| Safari | 14+ | 完全支持 |
| Edge | 90+ | 完全支持 |

### 5.3 可访问性

- 所有交互元素支持键盘操作
- 图片上传区支持屏幕阅读器
- 颜色对比度符合 WCAG AA 标准（深色主题下文字与背景对比度 >= 4.5:1）

### 5.4 安全

- 所有图片处理在本地完成，不上传服务器
- 不收集用户数据
- 不使用第三方追踪脚本

## 8. 核心算法

### 8.1 像素化 Pipeline

```
原始图片 -> [可选：裁剪] -> [可选：选区遮罩] -> 降采样 -> 颜色量化 -> 调色板映射 -> 输出
```

### 8.2 降采样（Downsample）

将原图缩小到目标分辨率，再放大回原始尺寸，形成块状像素效果。

```typescript
interface DownsampleOptions {
  blockSize: number;                 // 像素块大小（2~64）
  algorithm: 'nearest' | 'average';  // 最近邻 / 平均采样
}
```

- **Nearest**：每个像素块取中心点颜色，速度快，效果锐利
- **Average**：每个像素块取区域内平均颜色，效果更平滑

### 8.3 颜色量化（Quantize）

将降采样后的颜色缩减到有限数量。

```typescript
interface QuantizeOptions {
  method: 'none' | 'median-cut' | 'fixed-palette';
  maxColors?: number;    // 最大颜色数（2~256）
  palette?: RGB[];       // 固定调色板（预设模式使用）
}
```

- **none**：不量化，保留降采样后的所有颜色
- **median-cut**：自适应提取主要颜色，适合普通照片
- **fixed-palette**：使用预设调色板映射到最近颜色，适合复古硬件模拟

### 8.4 选区遮罩（MaskApply）

```typescript
interface MaskOptions {
  type: 'rectangle' | 'circle' | 'polygon' | 'freehand';
  invert: boolean;       // false=选区内像素化, true=选区外像素化
  data: SelectionData;   // 各类型对应的几何数据
}
```

**实现方式：** 先对整个图片做像素化处理，再用 Canvas `globalCompositeOperation` 或像素级 mask 叠加原图和像素化图。

**多边形点选实现：**
- 用户点击画布添加顶点
- 顶点间自动连线
- 双击最后一个顶点或点击第一个顶点闭合多边形
- 闭合后填充半透明高亮表示选区

**自由手绘实现：**
- 用户按住鼠标拖拽绘制任意路径
- 释放鼠标后自动用直线连接起点和终点形成闭合区域
- 使用纯 JS 射线法（ray-casting）判断像素是否在选区内，避免每像素调用 Canvas API 的性能瓶颈

### 8.5 人物像素风模式

```typescript
type PersonMode = 'normal' | 'cutout' | 'style' | 'sprite';

interface PersonOptions {
  mode: PersonMode;
  // normal:   与普通图片相同处理
  // cutout:   使用 @mediapipe/selfie-segmentation 分割人像
  //           背景处理方式：keep(保留) / pixelate(像素化) / color(纯色填充)
  // style:    轮廓增强 + 特定配色
  // sprite:   多图输入，统一像素化后拼接为 Sprite Sheet
}
```


```
  │  (Worker)    │
  └──────┬───────┘

  ┌──────────────┐

  │   Preview    │
  └──────────────┘
         |
         ▼

         |
         ▼
  ┌──────────────┐
  │ Full Process │  用原图生成高质量输出
  │  (Worker)    │
  └──────┬───────┘

  │              │
  └──────────────┘
```

### 10.3 性能优化策略

1. **缩略图预览优先** — 用户调整参数时，先用缩略图（最长边 800px）生成预览，0.5s 无操作后再用原图生成高质量版本
2. **Web Worker 处理** — 所有 `PixelEngine.process()` 调用都通过 Worker 执行，主线程只负责 Canvas 渲染
3. **防抖处理** — 滑块拖动时使用 100ms 防抖，避免频繁触发处理
4. **历史快照** — 每次用户"完成一次操作"（如松开滑块、完成框选）时保存参数快照

## 13. 风险与假设

### 13.1 风险

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|
| 大图片处理导致浏览器崩溃 | 中 | 高 | 限制最大尺寸（4096×4096），超限提示压缩 |
| @mediapipe/selfie-segmentation 加载缓慢 | 中 | 中 | 懒加载，首次使用时提示加载中 |
| Web Worker 在旧浏览器不支持 | 低 | 低 | 检查兼容性，不支持时降级到主线程 |
| 多边形/自由手绘选区性能差 | 中 | 中 | 使用 Canvas isPointInPath，优化路径复杂度 |

### 13.2 假设

- 用户设备支持 Canvas 2D 和 Web Workers
- 用户浏览器为现代浏览器（Chrome 90+/Firefox 88+/Safari 14+）
- 用户图片为常见格式（PNG/JPEG/WebP）
- @mediapipe/selfie-segmentation 模型可从 CDN 正常加载

## 14. 决策记录

| 日期 | 决策 | 选项 | 选择 | 理由 |
|------|------|------|------|------|
| 2026-05-25 | 架构 | 前端/后端/混合 | 纯前端 | 零延迟预览、零部署成本、隐私友好 |
| 2026-05-25 | 技术栈 | React/Vue/原生 | React + Vite + TS + Tailwind | 现代标准组合，框选交互和状态管理更清晰 |
| 2026-05-25 | UI风格 | 现代/复古/专业/活泼 | 复古游戏风 | 与像素主题呼应，用户选择 |
| 2026-05-25 | 引擎架构 | MVP/完整/模块化 | 模块化引擎 | 预设系统和多模式天然适合插件式架构 |
| 2026-05-25 | 人物抠图 | 算法选择 | @mediapipe/selfie-segmentation | 纯前端可用，无需后端 |
| 2026-05-25 | 精灵图 | 输入方式 | 多图上传拼接 | 单图生成多角度需要AI，纯前端不可行 |
| 2026-05-25 | GIF导出 | 是否支持 | 暂不实现 | 单帧转GIF意义不大，P2优先级 |
| 2026-05-25 | 裁剪与框选 | 流程关系 | 可独立使用 | 用户确认灵活流程 |
