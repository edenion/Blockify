## 1. 项目概述

一款纯前端图片像素化工具网站。用户上传图片后，可通过实时预览调整参数，将图片转换为像素艺术风格。支持裁剪、框选局部处理、多种复古硬件预设、自定义调色板，以及人物像素风多模式输出。

### 1.1 核心定位
- **目标用户**：像素艺术爱好者、游戏开发者、设计师、普通用户（头像/插画制作）
- **使用场景**：快速将照片转为像素风格、生成复古游戏素材、制作像素风头像
- **核心价值**：零成本、零上传、实时预览、一键导出

### 2.2 设计原则

1. **引擎层零依赖 React** — 纯 TypeScript + Canvas API，可独立测试和复用
2. **状态单向流动** — UI 状态变更 → 调用引擎 → 生成结果 → 渲染到 Canvas
3. **预设即配置** — 每个预设是纯数据对象，引擎根据配置执行对应处理参数
4. **算法可插拔** — 新算法通过 `PixelEngine.registerAlgorithm()` 注册，无需修改核心
5. **缩略图预览优先** — 实时预览使用缩略图，导出时使用原图保证质量

## 4. 核心算法

### 4.1 像素化 Pipeline

```
原始图片 → [可选：裁剪] → [可选：选区遮罩] → 降采样 → 颜色量化 → 调色板映射 → 输出
```

### 4.2 降采样（Downsample）

将原图缩小到目标分辨率，再放大回原始尺寸，形成块状像素效果。

```typescript
interface DownsampleOptions {
  blockSize: number;                 // 像素块大小（2~64）
  algorithm: 'nearest' | 'average';  // 最近邻 / 平均采样
}
```

- **Nearest**：每个像素块取中心点颜色，速度快，效果锐利
- **Average**：每个像素块取区域内平均颜色，效果更平滑

### 4.3 颜色量化（Quantize）

将降采样后的颜色缩减到有限数量。

```typescript
interface QuantizeOptions {
  method: 'none' | 'median-cut' | 'fixed-palette';
  maxColors?: number;    // 最大颜色数（2~256）
  palette?: RGB[];       // 固定调色板（预设模式使用）
}
```

- **none**：不量化，保留降采样后的所有颜色
- **median-cut**：自适应提取主要颜色，适合普通照片
- **fixed-palette**：使用预设调色板映射到最近颜色，适合复古硬件模拟

### 4.4 选区遮罩（MaskApply）

```typescript
interface MaskOptions {
  type: 'rectangle' | 'circle' | 'polygon' | 'freehand';
  invert: boolean;       // false=选区内像素化, true=选区外像素化
  // 各类型对应的几何数据...
}
```

实现方式：先对整个图片做像素化处理，再用 Canvas `globalCompositeOperation` 或像素级 mask 叠加原图和像素化图。

### 4.5 人物像素风模式

```typescript
type PersonMode = 'normal' | 'cutout' | 'style' | 'sprite';

interface PersonOptions {
  mode: PersonMode;
  // normal:   与普通图片相同处理
  // cutout:   使用 @mediapipe/selfie-segmentation 分割人像，背景可选处理
  // style:    轮廓增强 + 特定配色
  // sprite:   多图输入，统一像素化后拼接为 Sprite Sheet
}
```

## 5. 预设系统

### 5.1 预设数据结构

```typescript
interface Preset {
  id: string;
  name: string;
  category: 'hardware' | 'theme' | 'custom';
  config: {
    downsample: {
      blockSize: number;
      algorithm: 'nearest' | 'average';
    };
    quantize: {
      method: 'none' | 'median-cut' | 'fixed-palette';
      maxColors?: number;
      palette?: RGB[];
    };
    edgeEnhance?: boolean;
    dithering?: boolean;
  };
}
```

### 5.2 内置预设清单

**硬件模拟（Hardware）：**
| 预设 | 分辨率 | 调色板 | 特点 |
|------|--------|--------|------|
| GameBoy | 160×144 | 4色绿灰 | 经典掌机风格 |
| NES | 256×240 | 56色可用 | 任天堂限制调色板 |
| CGA | 320×200 | 4色 | 高对比 Cyan/Magenta |
| EGA | 640×350 | 16色 | 更丰富的早期PC色 |

**创意主题（Theme）：**
| 预设 | 描述 |
|------|------|
| Cyberpunk | 霓虹紫 + 青 + 粉，高对比 |
| Vaporwave | 粉紫渐变，梦幻感 |
| Wasteland | 棕褐色调，低饱和 |
| Mono | 纯黑白，高对比 |

```typescript
  deletePreset(id: string): void;

  // ...

```

### 5.4 预设注册机制


## 6. 数据流与状态管理

### 6.1 全局状态（Zustand）

```typescript
interface AppState {
  // 图片数据
  image: {
    original: HTMLImageElement | null;
    cropped: HTMLImageElement | null;
    thumbnail: HTMLImageElement | null;
  };

  // 处理参数
  params: {
    blockSize: number;
    algorithm: 'nearest' | 'average';
    presetId: string | null;
    customOverrides: Partial<PresetConfig>;
  };

  // 选区
  selection: {
    active: boolean;
    type: 'rectangle' | 'circle' | 'polygon' | 'freehand';
    invert: boolean;
    data: SelectionData;
  };

  // 人物模式
  personMode: PersonMode | null;
  personImages: HTMLImageElement[];

  // 历史记录
  history: {
    past: HistorySnapshot[];
    future: HistorySnapshot[];
  };

  // 导出设置
  exportFormat: 'png' | 'sprite-sheet';

  // UI 状态
  ui: {
    showCompare: boolean;
    compareMode: 'split' | 'slider';
    isProcessing: boolean;
    activePanel: 'presets' | 'params' | 'export';
  };
}
```

### 6.2 数据流图

```
用户操作（调参/选预设/框选）
         │
         ▼
  ┌──────────────┐
  │  Zustand     │◄──── 撤销/重做操作历史快照
  │  State       │
  └──────┬───────┘
         │ params changed
         ▼
  ┌──────────────┐
  │ ThumbPreview │  用缩略图快速生成预览
  │  (Worker)    │
  └──────┬───────┘
         │ result
         ▼
  ┌──────────────┐
  │   Canvas     │  渲染预览
  │   Preview    │
  └──────────────┘
         │
         ▼
  用户点击"导出"
         │
         ▼
  ┌──────────────┐
  │ Full Process │  用原图生成高质量输出
  │  (Worker)    │
  └──────┬───────┘
         │ result
         ▼
  ┌──────────────┐
  │ ExportManager│  下载/Sprite Sheet拼接
  │              │
  └──────────────┘
```

### 6.3 关键设计决策

1. **缩略图预览优先** — 用户调整参数时，先用缩略图（最长边 800px）生成预览，0.5s 无操作后再用原图生成高质量版本
2. **Web Worker 处理** — 所有 `PixelEngine.process()` 调用都通过 Worker 执行，主线程只负责 Canvas 渲染
3. **历史快照** — 每次用户"完成一次操作"（如松开滑块、完成框选）时保存参数快照，支持撤销

## 10. 决策记录

| 日期 | 决策 | 选项 | 选择 | 理由 |
|------|------|------|------|------|
| 2026-05-25 | 架构 | 前端/后端/混合 | 纯前端 | 零延迟预览、零部署成本、隐私友好 |
| 2026-05-25 | 技术栈 | React/Vue/原生 | React + Vite + TS + Tailwind | 现代标准组合，框选交互和状态管理更清晰 |
| 2026-05-25 | UI风格 | 现代/复古/专业/活泼 | 复古游戏风 | 与像素主题呼应，用户选择 |
| 2026-05-25 | 引擎架构 | MVP/完整/模块化 | 模块化引擎 | 预设系统和多模式天然适合插件式架构 |
| 2026-05-25 | 人物抠图 | 算法选择 | @mediapipe/selfie-segmentation | 纯前端可用，无需后端 |
| 2026-05-25 | 精灵图 | 输入方式 | 多图上传拼接 | 单图生成多角度需要AI，纯前端不可行 |
| 2026-05-25 | GIF导出 | 是否支持 | 暂不实现 | 单帧转GIF意义不大，P2优先级 |
| 2026-05-25 | 裁剪与框选 | 流程关系 | 可独立使用 | 用户确认灵活流程 |
